# Default Open Graph / Social Share Image

Place the default social sharing image here as `default.jpg`.

Required specifications:
- Filename: `default.jpg`
- Dimensions: **1200 × 630 px** (standard Open Graph / Twitter card)
- Format: JPEG, quality 85–90
- Content: César Barón brand image — name, tagline, or architectural photography
- Max file size: ~200 KB

Once the image is ready:
1. Copy it to `public/images/og/default.jpg`
2. Uncomment the `og:image` line in `nuxt.config.ts`
